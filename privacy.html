Privacy Policy

Last updated: 8 November 2026

"Know in 30" is a private tool operated by one person (the owner) to publish videos to the owner's own YouTube channels. It has no other users.

What the tool accesses

Using Google OAuth, with the owner's own Google account only, the tool uses the YouTube Data API and YouTube Analytics API to: upload videos, set titles, descriptions, thumbnails and schedules, and read view and watch-time statistics for the owner's own channels.

What is collected and stored

The tool does not collect, store or process personal data of any other person. OAuth access tokens for the owner's account are kept in the owner's private, access-controlled GitHub repository secrets and are used only to perform the actions above.

Sharing

Data obtained through Google APIs is not sold, shared, or transferred to third parties and is not used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion

The owner can revoke the tool's access at any time at myaccount.google.com/permissions, which invalidates all stored tokens.
